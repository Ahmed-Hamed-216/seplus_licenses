# seplus_licenses — سيرفر ترخيص ذاتي لقالب SeoPlus V9

بديل مستضاف ذاتيًا لقنوات الترخيص/التحكم في قالب SeoPlus V9 بعد توقف دعم البائع،
بنفس أسلوب حل قالب Squeeze السابق: **بدون أي تعديل على كود القالب المشفر**.

## ماذا يستبدل license-check.js؟

قنوات البائع الأربع المكتشفة بعد فك التشفير:

| # | القناة | الأصل (سيرفر البائع) | البديل |
|---|--------|----------------------|--------|
| 1 | Database V9 — سكربت عن بُعد يُعمل له `eval()` | Blogger feed صفحة "Database V9 Scripts" | بايلود مرقّع مدمج داخل license-check.js يُزرع في `sessionStorage['storg']` قبل أن يقرأه القالب |
| 2 | `sp_db` — JSONP callback بفحص هوية المصدر ثم eval | callback من feed البائع | override بـ `Object.defineProperty` غير قابل للاستبدال ينفّذ البايلود المرقّع فقط |
| 3 | `cprF` — فحص شارة الفوتر | صفحة "seoplus activations" (15,590 رقم مدونة) | معطّل داخل البايلود |
| 4 | `spscxcb` — شاشة "لماذا توقف المدونة؟" | نفس الصفحة + مدونتك غير مدرجة فيها | معطّل داخل البايلود |

> سبب المشكلة الأصلي: رقم مدونتك `8176772930665578124` غير موجود في قائمة
> الترخيص الخاصة بالبائع، فكانت شاشة القتل تظهر في الصفحات المفردة.

## التركيب (في قالب بلوجر — HTML/JavaScript)

قبل `</body>` مباشرة (بعد سكربتات القالب):

```html
<script>window.FE_LIC={blogid:"8176772930665578124"};</script>
<script src='https://ahmed-hamed-216.github.io/seplus_licenses/license-check.js'></script>
```

ثم امسح الكاش/افتح بنافذة خاصة أول مرة (القالب يخزّن البايلود في sessionStorage).

## إدارة التراخيص

عدّل مصفوفة `LICENSES` داخل license-check.js وأضف أرقام المدونات المصرح بها،
ثم اعمل commit — التغيير يسري على كل المدونات فورًا. ترك المصفوفة فارغة
يعني "يكفي وجود FE_LIC.blogid".

## الملفات

- `license-check.js` — الملف الوحيد المطلوب استضافته (البايلود مدمج بداخله).
